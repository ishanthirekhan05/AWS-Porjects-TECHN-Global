Six starting points

Career paths for curious builders

Start with one path and learn by doing.

01

Software Developer

Design, build, test, and maintain software that solves problems for people and organizations.

Required skills

  • Problem solving
  • Data structures
  • Debugging
  • Git

Recommended technologies

Java or Python, SQL, Git, and a testing framework.

Beginner roadmap

  1. Learn programming fundamentals.
  2. Practice data structures and algorithms.
  3. Build and test a small application.

Learning resources

Language documentation, Git guides, and introductory data-structure courses.

Suggested project

Build a command-line expense tracker with saved data and tests.

02

Web Developer

Create useful, accessible websites and web applications for real user needs.

Required skills

  • HTML
  • CSS
  • JavaScript
  • Accessibility

Recommended technologies

HTML5, CSS3, JavaScript, browser DevTools, and GitHub.

Beginner roadmap

  1. Learn semantic HTML and page structure.
  2. Practice responsive CSS layouts.
  3. Add accessible JavaScript interactions.

Learning resources

MDN Web Docs, web accessibility guides, and browser developer tools.

Suggested project

Create a responsive student portfolio with a project filter.

03

Data Analyst

Use data preparation, analysis, and communication to help people understand patterns and decisions.

Required skills

  • Critical thinking
  • Statistics
  • Data cleaning
  • Communication

Recommended technologies

Python, SQL, spreadsheets, and a data visualization tool.

Beginner roadmap

  1. Learn spreadsheets and basic statistics.
  2. Query and clean a small dataset with SQL.
  3. Explain findings with clear charts.

Learning resources

SQL documentation, statistics primers, and visualization principles.

Suggested project

Analyze a public transport dataset and publish a short findings report.

04

Cloud/AWS Engineer

Plan, configure, and monitor cloud infrastructure that helps applications run reliably.

Required skills

  • Linux
  • Networking
  • Security basics
  • Automation

Recommended technologies

AWS core services, Linux, Git, networking tools, and infrastructure concepts.

Beginner roadmap

  1. Learn networking, Linux, and cloud basics.
  2. Study S3, IAM, and compute concepts.
  3. Deploy and document a simple static website.

Learning resources

AWS Skill Builder, AWS documentation, and introductory cloud labs.

Suggested project

Host a static portfolio on S3 and document its deployment steps.

05

AI/ML Engineer

Prepare data and build software that uses machine-learning models to support useful tasks.

Required skills

  • Python
  • Mathematics
  • Data handling
  • Evaluation

Recommended technologies

Python, NumPy, pandas, scikit-learn, and notebook-based workflows.

Beginner roadmap

  1. Build Python and statistics foundations.
  2. Explore data preparation and model evaluation.
  3. Compare a few simple models on clean data.

Learning resources

Python documentation, scikit-learn guides, and beginner machine-learning courses.

Suggested project

Classify a small public dataset and explain model limitations.

06

Cybersecurity

Protect systems and information by understanding risks, controls, monitoring, and responsible practice.

Required skills

  • Networking
  • Linux
  • Risk awareness
  • Documentation

Recommended technologies

Linux, networking tools, Python scripting, logs, and security testing labs.

Beginner roadmap

  1. Understand networks, operating systems, and common risks.
  2. Practice safely in legal learning labs.
  3. Document findings and recommended controls.

Learning resources

OWASP guidance, Linux documentation, and structured security fundamentals labs.

Suggested project

Create a home-lab security checklist and explain each recommended control.
